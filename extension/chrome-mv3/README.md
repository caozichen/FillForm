# FillForm（一键填充助手测试版）

> 此文件会随构建复制到可加载的扩展目录。

## 当前状态

- 已提供可加载的 MV3 骨架（FillForm 品牌）。
- 已打通基础流程：
  - 字段识别（语义 + 结构启发式）
  - 一键填充（按字段类型生成 mock 值）
  - 页面内悬浮球入口（上下拖动、右侧吸附）
  - 设置中心（模式、提供方、邮箱池、curl 模板保存）
- UI Phase 1 已完成：
  - 页面内控制中心升级为卡片化工作台
  - 弹窗控制中心与页面内工作台视觉统一
  - 设置中心升级为侧导航 + 主内容布局
  - 模板列表已纳入模板中心分区展示

## 目录结构

- `manifest.json`：插件清单
- `background.js`：消息路由、识别/填充编排
- `content/agent.js`：页面识别、填充执行、悬浮球 UI
- `core/`：内核模块（字段图、数据生成、模板引擎）
- `popup.*`：控制中心（弹窗）
- `options.*`：设置中心
- `ui/overlay.css`：页面内悬浮球样式

## 加载方式

1. 打开 `chrome://extensions`
2. 开启开发者模式
3. 选择“加载已解压的扩展程序”
4. 选择仓库中的 `extension\chrome-mv3` 目录

## 说明

- 该版本是重构进行中的基线版本。
- `extension/chrome-mv3` 是由 `npm run build` 自动刷新的可提交产物。
- 后续会按 P0/P1/P2 逐步增强：
  - P0：识别准确性、区域边界、地址/单选/多选/日期稳定性
  - P1：UI 模板 + API 模板联动
  - P2：模板中心与 API 编辑器深度重构、低置信模型兜底
